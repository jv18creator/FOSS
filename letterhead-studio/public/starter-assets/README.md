# Starter hero photos

These JPEGs are used by default letterhead templates (`/templates/occasions/*.letterhead.json`).

Current files were fetched from [Lorem Picsum](https://picsum.photos/) for reliable CI/build downloads. Replace with licensed Unsplash (or your own) photography and re-run:

```bash
npm run build
npx vite preview --port 5174 &
EDITOR_URL=http://127.0.0.1:5174 npm run rebuild:starters
```

Keep filenames: `atelier-hero.jpg`, `violet-hero.jpg`, `ledger-hero.jpg`.
