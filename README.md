Letterhead template editor demo lives in **`letterhead-studio/`**.

```bash
cd letterhead-studio && npm install && npm run dev
```

See [letterhead-studio/README.md](letterhead-studio/README.md) for features and scripts.

**Cursor:** [`.cursor/mcp.json`](.cursor/mcp.json) registers **Playwright MCP** for this workspace.
